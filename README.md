# 💻 Learning CSS

Starter files for a coding exercise that introduces CSS. You will style six practice pages,
learning how to change colors, fonts, spacing, borders, backgrounds, and page layout, then
publish the finished site to GitHub Pages.

This repo also includes the editor and Git configuration and the pull request template that every
assignment in this course uses.

> [!NOTE]
> `.editorconfig`, `.gitattributes`, `.gitignore`, `.noai`, and the `.github` and `.idea`
> folders are setup files that keep assignments consistent. Leave them alone. `index.html`,
> `css01.html`–`css06.html`, and `reset.css` are your starter files — keep them in the repo.

## 📂 Where Your Files Go

> [!IMPORTANT]
> Open the whole project **folder** in your editor, not a single HTML file on its own.
> Your pages link to CSS files, and your editor can only resolve those paths if it can see
> every file in the project.

Every starter file is already in the **root folder** of this repo — the same folder as this
README. Edit them where they are:

```
index.html
css01.html
css02.html
css03.html
css04.html
css05.html
css06.html
reset.css
```

Do not rename or move these files. `index.html` links to each practice page by name, and it
has to keep its name and stay in the root folder — GitHub Pages publishes from the root and
serves `index.html` as your home page. Rename it and your site will 404. The external CSS file
you create in Part 6.1 goes in the root folder too, unless the video tells you otherwise.

## 🤖 AI Policy

Work on this assignment must be your own. Do not use AI coding assistants — including
GitHub Copilot, Cursor, ChatGPT, Claude, or JetBrains AI Assistant — to generate,
complete, or rewrite your code.

You should be able to explain any line of your submission. You may be asked to do so.

This repo includes a `.noai` file, which disables JetBrains AI Assistant for the project
in IDEs like WebStorm. Leave it in place. It is a reminder of the policy above, not a
substitute for it — following the policy is still your responsibility.

> [!NOTE]
> The `.noai` file does **not** turn off WebStorm's local Full Line code completion. Turn that
> off yourself as part of the [one-time setup](.github/WEBSTORM_SETUP.md) (step 5).

> [!CAUTION]
> Late or missing submissions are graded on what is in the pull request at the deadline, so push your final commits
> before you submit.
